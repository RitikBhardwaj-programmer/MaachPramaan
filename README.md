# Maach Pramaan

**An auditable sample survey for Assam's pond and tank fish production.**
Solution for NESFIC 2026 challenge **NESFIC-D-32**: Scientific Sample Survey for Pond and Tank Aquaculture
Production Estimation (Fishery Department, Assam).

> **All results in this repository are SIMULATED.** They come from synthetic districts with a known true total.
> No real Assam data has been used.

## What it does

Assam now estimates pond and tank production as water area × one assumed productivity, with no margin of error.
Maach Pramaan replaces that with a probability sample survey:

- About 200 ponds per district, drawn by a random rule that anyone can re-run from the frozen frame and the published seed.
- A short harvest diary per harvest, checked by field weighing on a sub-sample (two-phase design).
- District and State production estimates with 95% confidence intervals, plus productivity (t/ha).
- Data-quality flags that mark suspect records but never overwrite them, and an audit log of every run.

## Quick start (Windows, Python 3.11+)

```
py -3 -m venv .venv
.venv/Scripts/python -m pip install -e ".[test]"
.venv/Scripts/python -m pytest
```

## Reproduce a run

Each `results/<run>/command.txt` holds the exact command and seeds. For example, the v0.5 confirmation run:

```
.venv/Scripts/python -m d32.simulate --reps 1000 --v05 --scenarios S1,S2,S3,S4,S5,S4x,S5x --pop-seed 20261107 --master-seed 9931 --workers 12 --out results/v0.5
```
