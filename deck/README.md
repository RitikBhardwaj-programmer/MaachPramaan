Source of the 12-slide pitch deck, published as a private Slides artifact:
https://claude.ai/artifact/H5gYskR2BArHHm8LCLaj8G

These files are the artifact's data files (`deck.json` for order and fonts, `slides/*.html` for one slide each, speaker notes in `<aside>`). They render inside the Slides artifact type, not as a standalone page. To change the deck, edit them and republish to the same artifact URL. Export to PPTX or PDF from the artifact.
